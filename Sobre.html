Sobre a PokéDex Web

Conhecendo o projeto

A PokéDex Web é um projeto desenvolvido com o objetivo de apresentar informações sobre diferentes Pokémon, seus tipos e características.

O site foi criado utilizando tecnologias fundamentais do desenvolvimento web, buscando oferecer uma navegação simples, organizada e agradável.

Tecnologias utilizadas

HTML

Estrutura e organização das páginas.

CSS

Estilização, cores e organização visual.

JavaScript

Funcionalidades e interações do site.
